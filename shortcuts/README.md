# iPhone 15 / iOS 快捷指令配置指南

利用 iOS 系统的「快捷指令」App，无需安装任何第三方应用，即可与 ChaCha AI 云端服务无缝打通。

## 步骤一：创建快捷指令
1. 打开 iPhone 自带的 **「快捷指令」** App；
2. 点击右上角 **「+」** 新建；
3. 重命名为：`ChaCha AI`；
4. 依次添加以下 5 个动作：
   * **要求输入**：提示词填 `你想问什么？`（输入类型为文本）
   * **URL**：填入您的服务端接口地址，例如 `http://your-server-ip:8088/api/chat`
   * **获取 URL 的内容**：
     * 方法：`POST`
     * 请求体：`JSON`
     * 添加 3 个字段：
       * `prompt` (文本)：选择变量 `[要求输入]`
       * `token` (文本)：填入您服务端的安全密钥
       * `continue` (文本)：`true`
   * **从输入中获取词典值**：键为 `reply`
   * **快速查看**：显示 `[词典值]`（支持长文本全屏上下滑动翻页）

## 步骤二：绑定 iPhone 15 硬件唤醒（轻点背面两下）
1. 进入 iPhone **「设置」 -> 「辅助功能」 -> 「触控」 -> 「轻点背面」**；
2. 选择 **「轻点两下」**；
3. 在列表底部的“快捷指令”中，勾选 **「ChaCha AI」**；
4. 无论在任何界面，拿起手机在背面轻轻敲击两下，即可瞬间呼出 AI 对话输入框！
